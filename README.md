# Telegram Signals Bot

Auto-posts trading signals to your Telegram group 5x/day with an affiliate CTA under every signal. Uses free market data APIs — no paid subscriptions needed to start.

---

## What it does

- Fetches real price data from CoinGecko (crypto) and Alpha Vantage (forex, stocks, commodities)
- Generates BUY/SELL signals using RSI + EMA crossover rules
- Posts formatted signal messages at scheduled times (UTC: 07:00, 09:00, 12:00, 15:00, 18:00)
- Appends your affiliate CTA link under every single post
- Rotates across 11 assets (BTC, ETH, SOL, EUR/USD, GBP/USD, USD/JPY, Gold, Oil, S&P500, Nasdaq, BNB)
- Falls back to last-known prices if APIs are rate-limited

## Setup — 4 steps

### 1. Create your Telegram bot

1. Open Telegram, search for **@BotFather**
2. Send `/newbot` and follow the prompts
3. Copy the **Bot Token** (looks like `123456:ABCdef...`)
4. Add the bot to your group as **admin** with permission to post messages
5. Get your Group ID: forward any message from your group to **@userinfobot** — it shows the chat ID (a negative number like `-1001234567890`)

### 2. Get a free Alpha Vantage API key

1. Go to [alphavantage.co](https://alphavantage.co)
2. Click **Get Free API Key**
3. Copy the key (free tier = 25 requests/day — enough for 5 signals)

### 3. Deploy to Railway (recommended — free)

1. Push this folder to a GitHub repo
2. Go to [railway.app](https://railway.app) → **New Project** → **Deploy from GitHub**
3. Select your repo
4. Go to **Variables** and add:

```
BOT_TOKEN          = your bot token
GROUP_ID           = -1001234567890
AFFILIATE_LINK     = https://yourbroker.com/r/YOURCODE
ALPHA_VANTAGE_KEY  = your AV key
SIGNALS_PER_DAY    = 5
```

5. Railway auto-detects the Procfile and deploys. Done.

### 4. Test it locally (optional)

```bash
pip install -r requirements.txt
cp .env.example .env   # fill in your values
python -c "
import asyncio, os
from dotenv import load_dotenv
load_dotenv()
from signals.generator import SignalGenerator
from bot import format_signal

async def test():
    g = SignalGenerator()
    s = await g.get_signal(0)
    print(format_signal(s, os.environ['AFFILIATE_LINK']))

asyncio.run(test())
"
```

## Signal logic

Each signal is generated by:

1. Fetching 30 days of daily close prices
2. Calculating **RSI(14)** and **EMA(9) vs EMA(21)**
3. Applying rules:
   - RSI < 40 + EMA9 > EMA21 → Strong BUY
   - RSI > 60 + EMA9 < EMA21 → Strong SELL
   - RSI < 45 → BUY (oversold bias)
   - RSI > 55 → SELL (overbought bias)
   - Neutral → follows EMA trend direction
4. TP/SL calculated as % of entry price (wider for crypto, tighter for forex)
5. Confidence score derived from RSI distance from 50

## Customising

**Change post times** — edit `POST_HOURS` in `bot.py`:
```python
POST_HOURS = [7, 9, 12, 15, 18]  # UTC hours
```

**Add/remove assets** — edit `ASSET_POOL` in `signals/generator.py`

**Change the CTA text** — edit `CTA_TEXT` in `bot.py`

**Increase signals/day** — set `SIGNALS_PER_DAY=5` (max 5 on free AV tier without extra keys)
